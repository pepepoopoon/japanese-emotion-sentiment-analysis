# Данные

Рабочая схема — UTF-8 CSV со столбцами `text_id`, `text`, `polarity` и восемью
бинарными метками: `emotion_joy`, `emotion_sadness`, `emotion_anticipation`,
`emotion_surprise`, `emotion_anger`, `emotion_fear`, `emotion_disgust`, `emotion_trust`.
Полярность принимает `negative`, `neutral` или `positive`.

`smoke.csv` детерминированно создан из вымышленных японских фраз; это не часть
WRIME и не материал из социальных сетей.

Полноценный источник — [официальный WRIME](https://github.com/ids-cv/wrime). Для
полярности нужен ver.2; интенсивности эмоций следует преобразовывать в бинарные метки
по заранее зафиксированному правилу (например, `> 0`). Проверяйте актуальный `LICENSE`
до использования. На момент подготовки проекта он указан как CC BY-NC-ND 4.0:
коммерческое использование и распространение производных версий запрещены. В более
ранних карточках WRIME отдельно формулировались ограничения «research purposes only»
и запрет перераспространения. Поэтому этот репозиторий **не скачивает, не копирует и не
перепубликовывает WRIME**: пользователь получает данные напрямую у авторов и отвечает
за соблюдение действующих условий.
